# Asbestos Analysis Manager

A web application for managing asbestos analysis projects.

---

## Overview

This application was developed as a personal portfolio project.

It is designed to manage asbestos analysis projects and samples using a relational database.

---

## Features

- Project registration
- Project list
- Project details
- Project editing
- Project deletion

---

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express
- SQLite

---

## Database

### projects

- Customer Name
- Report Number
- Received Date
- Analysis Date
- Analyst
- Reviewer
- Title

### samples

- Sample No.
- Sampling Location
- Sample Name
- Asbestos Content
- Asbestos Type
